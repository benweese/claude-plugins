# Books API — test plan

## Acceptance criteria
- AC-1: GET /api/books lists the books with id, title and author.
- AC-2: POST /api/books adds a book (201).
- AC-3: A missing title is rejected with 400.
- AC-4: DELETE /api/books/:id removes a book.

#### #0102 — adds a book (AC-2)
#### #0103 — rejects a missing title (AC-3)
